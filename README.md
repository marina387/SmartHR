# SmartHR — дипломный проект

Локальное Flask-приложение для работы с резюме, вакансиями, интервью и корпоративными документами. Автоматическая оценка помогает HR сравнить кандидата с требованиями вакансии; окончательное решение принимает человек.

## Возможности

- Загрузка резюме, карточки кандидатов и архив.
- Оценка по критериям с весами, комментариями и историей результатов.
- Редактирование резюме с переоценкой и перенос на другую вакансию.
- Этапы рассмотрения, календарь интервью и обратная связь.
- Библиотека документов: загрузка, чтение, замена версии, переименование, удаление из поиска.
- Чат по кандидатам и документам с источниками и сохранением диалогов. Изменения из чата требуют подтверждения.
- Личный вход, роли HR/администратора, автоматическое авторство и журнал действий.
- Целостность SQLite, резервные копии и защита карточки от устаревшего редактирования.

## Запуск в Windows

Откройте `start_smarthr.bat`, затем http://127.0.0.1:5000/ . При первом запуске создаётся `.venv-run` и устанавливаются зависимости исполнения. Остановка — Ctrl+C в окне сервера.

Первый администратор создаётся на `/setup`. Готовых логинов и паролей нет. Логин допускает кириллицу и латиницу, пароль — от 12 символов.

Ручная установка (Python 3.12+):

```powershell
python -m venv .venv-run
.\.venv-run\Scripts\python.exe -m pip install -r requirements.txt -r requirements-chat.txt
.\.venv-run\Scripts\python.exe run_smarthr.py
```

Скрипт запуска проверяет окружение, резервирует существующую базу и документы, применяет миграции и запускает сервер. Обучение при запуске не выполняется.

## Данные и модели

Рабочая база — `data/smarthr.db`, библиотека — `data/documents`, секрет сессии — `data/.session-secret`. Не удаляйте их при очистке.

Модель оценки: `models/matching_model.pkl` и `models/model_metadata.json`. Чат по умолчанию использует локальный `models/chat_model_real` и базовую модель `models/base_qwen`. Без совместимого чат-артефакта предусмотрен ограниченный `MockChatModel`.

В Git публикуются исходники, тесты, миграции и небольшая модель оценки с метаданными. Рабочая база, резюме, датасеты, секреты, логи и большие веса чата не публикуются. Скачанный репозиторий требует собственной подготовки локальных данных и больших артефактов.

## Проверки и обслуживание

```powershell
.\.venv-run\Scripts\python.exe -m pip install -r requirements-test.txt
.\.venv-run\Scripts\python.exe run_checks.py
.\.venv-run\Scripts\python.exe run_smarthr.py --check
.\.venv-run\Scripts\python.exe run_smarthr.py --diagnose
```

Для проверки JavaScript нужен Node.js. Тесты используют отдельную базу, обучение не запускается. Полный прогон перед очисткой: **361 тест, 0 ошибок и падений**, 27 октября 2026.

Полная резервная копия: остановите сервер и выполните `python run_smarthr.py --backup-only`. Проверка запущенного приложения: `/api/health`. Восстановление и ограничения описаны в [TECHNICAL.md](TECHNICAL.md).

## Структура

| Путь | Назначение |
|---|---|
| `app.py`, `run_smarthr.py`, `start_smarthr.bat` | Приложение и запуск |
| `src/` | Сервисы, маршруты, чат, поиск и интерфейс |
| `migrations/` | Версии схемы базы |
| `tests/`, `run_checks.py` | Автоматические проверки |
| `docs/sample_docs/` | Примеры документов для поиска |
| `models/` | Модели и метаданные |
| `scripts/`, `configs/`, `ml/` | Подготовка данных, обучение и эксперименты |
| `evaluation/` | Инструменты и результаты оценки моделей |
| `data/` | Локальные данные и резервные копии |

## Демонстрация на защите

1. Вход и вакансия с требованиями и весами.
2. Загрузка резюме, оценка с объяснениями и недостающими сведениями.
3. Редактирование с переоценкой, история, перенос на подходящую вакансию.
4. Назначение интервью и изменение этапа.
5. Вопросы чату о кандидате и документе с указанием источника.

Основная документация состоит из этого README и [технического описания](TECHNICAL.md). Служебные описания поставляемых моделей, исходных датасетов и сгенерированные отчёты относятся к самим артефактам.
