# Уведомления и резервный поиск альтернатив

Уведомления страниц используют собственный класс `app-notice`, не зависящий от скрытого состояния Bootstrap `.toast`. Ошибки показываются 9 секунд с ролью `alert`; прочие уведомления — 4,5 секунды с ролью `status`. Текст вставляется через `textContent`.

Поиск альтернатив сначала использует локальную семантическую модель. Если зависимость или её локальные файлы недоступны, поиск продолжает работу по распознанным требованиям, навыкам и существующей модели соответствия. Обязательные требования, минимальные балл и вероятность, критерии прироста и сильного совпадения остаются прежними. Исключается только недоступная проверка семантического сходства; это отдельный режим, а не эквивалент семантического поиска.

API возвращает `search_mode=structured`, предупреждение и `semantic_similarity=null`. Карточка показывает ограничение, а причина каждой рекомендации указывает, что семантическая проверка не выполнялась. Неожиданные ошибки расчёта не превращаются в успешные результаты. Скачивание и обучение моделей не выполняются. Сама операция поиска не записывает данные кандидата.

Проверки охватывают оба режима, исключение активных связей, закрытые вакансии и сохранение численных порогов. В браузере проверена видимая ошибка сохранения интервью без даты: сервер отклонил запрос, интервью не создано.
