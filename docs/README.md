# Минимальный объединённый проект

Этот проект объединяет:
- веб-оценку кандидатов по вакансиям;
- простой RAG-демо для обучения на небольшом наборе HR-документов.

## Быстрый старт

```bash
pip install -r requirements.txt
python app.py
```

## RAG-демо

```bash
python -m src.cli.app rag_demo --docs docs/sample_docs --query "Какие правила интервью закреплены в корпоративных документах?"
```
