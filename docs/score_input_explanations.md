# Объяснение сохранённых входных данных модели

Карточка кандидата и чат используют `explain_result`: в комментарий профессионального критерия добавляются сохранённые признаки стажа, минимального стажа вакансии и совпадения навыков. Эти признаки относятся к моменту сохранённого расчёта; текущая вакансия для их восстановления не используется.

Если `experience_years` присутствует в `missing_fields`, численный ноль описывается как подстановка при отсутствующих или нераспознанных данных, а не как установленное отсутствие опыта. При явно сохранённом нуле отображается «В расчёт передан профильный стаж: 0 лет». Ни один вариант не объявляется независимо проверенным фактом.

Указанные входные данные не являются атрибуцией причин прогноза. Процент совпадения навыков означает совпадение распознанных формулировок, не доказанное владение. Если признаки не сохранены или обязательный фильтр остановил расчёт, новые основания не выдумываются.

Для старых переносов метаданные карточки сверяются с историей: используются признаки записи с той же вакансией, итогом, разбивкой и вероятностью. Это устраняет сохранённые ранее признаки исходной вакансии при уже обновлённом итоге. Будущие переносы сохраняют признаки и пропуски вместе с новым результатом. Данные другой вакансии или другого результата не используются.

В предупреждении карточки пропущенные поля названы по-русски. Удалено утверждение, что все пропуски заменяются нейтральными значениями: для численной модели это неверно. Исходные баллы, комментарии в базе, архивные состояния, модель и обучение не изменяются. Новое объяснение формируется при отображении, поэтому доступно и для старых записей с сохранёнными признаками.
