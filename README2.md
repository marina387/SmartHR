# SmartHR — интеллектуальная платформа подбора персонала

SmartHR — это HR-платформа для подбора персонала, которая использует реальные данные о вакансиях и резюме, машинное обучение для оценки кандидатов и дообученную языковую модель для общения с рекрутером.

## 🌟 Основные возможности

- **Матчинг на реальных данных**: Модель оценена на 459k реальных вакансий и 12.9 млн резюме (данные с trudvsem.ru).
- **Чат-ассистент (LLM)**: Дообученная модель Qwen2.5-0.5B (через QLoRA), которая отвечает на вопросы о кандидатах строго по фактам из резюме, без галлюцинаций.
- **Альтернативные вакансии**: Автоматический поиск вакансий, куда кандидат подходит лучше текущей.
- **Сбор реальной обратной связи**: Встроенный UI для рекрутеров («Подходит / Не подходит»). Эти данные сохраняются для будущего переобучения модели на реальных метках.
- **RAG-поиск по документам**: Поиск ответов в корпоративных HR-документах (PDF, DOCX).

🧠 Как обучались модели
Модель матчинга (Matching Model)

    Скачано 459 000 вакансий и 12 900 000 резюме с trudvsem.ru.

    Данные сконвертированы скриптом convert_trudvsem_v2.py (очистка от PII, нормализация навыков и образования).

    Сгенерировано 887 000 пар «резюме-вакансия» (50% позитив, 50% негатив).

    Обучен GradientBoostingClassifier на 11 фичах (опыт, зарплата, совпадение навыков, образование).

Чат-модель (LLM)

    Из реальных данных сгенерировано 5000 QA-пар (build_real_chat_dataset.py).

    Каждый ответ построен на основе фактов из резюме (вердикт модели, опыт, навыки).

    Базовая модель Qwen/Qwen2.5-0.5B-Instruct дообучена через QLoRA (train_chat_model.py).

    Метрики: train_loss = 0.43, eval_loss = 0.31 (модель не переобучена).

    Модель сохранена в models/chat_model_real.

🔄 Сбор реальной обратной связи (для будущего улучшения)

Мы добавили кнопки «✅ Подходит / ❌ Не подходит» в карточку кандидата. Каждое нажатие сохраняется в БД.

Как накопить данные:

    Создайте 3–5 реальных кандидатов через UI (с настоящими резюме).

    Нажмите кнопку решения.

    Раз в неделю запускайте выгрузку:
python scripts/export_real_labels.py

Когда накопится 100+ решений, можно переобучить модель на реальных метках (а не на синтетических правилах):
python scripts/train_on_real_labels.py

Метрики будут честными (ROC-AUC 0.70–0.85), а модель — действительно полезной в продакшене.

📝 Лицензия

Проект использует открытые данные с портала «Работа в России» (trudvsem.ru) в соответствии с условиями их использования. Синтетические данные (например, chat_draft.jsonl) помечены флагом synthetic: true и не используются для финального обучения.
